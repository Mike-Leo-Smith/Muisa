# A1：因果事件级跟谱对照

这是**事件级算法实验**，没有经过音频检测器；不要把结果称为PCM端到端或真实演奏准确率。在线App保持不变。

```sh
node experiments/following/run.js
```

零依赖，固定12音短谱、12个可检查场景：clean、漏一音、漏四音/前向跳段、额外错音、重复拨弦、连续同音处额外拨弦、unknown、加速、停顿、回跳重弹、unknown噪声事件、强置信度无关音。标签独立存放，跟随器只收到音高/置信度/时戳，没有正确索引。

对照当前 `LiveAligner` 的三音前看，实验 `OnlineDP` 保留每个score位置的动态规划累计代价：extra0.8、skip0.65、wrong2.5，最优/次优差不足0.15则unknown；匹配必须音高差小于半音且confidence≥0.8。它是DTW风格的因果edit-distance格点，不是完整音频DTW、HMM或概率模型。单次复杂度O(谱长)，不等待未来事件；代价不是正确概率。

每个前缀接两种不同未来，验证已输出结果逐项一致；检查时间戳非单调拒绝，以及unknown和无关音不被谱面先验强判正确。离线 `alignOffline` 使用全片段，仅作明确标记的非因果对照。结果JSON包含全部输出、事件真值、precision/coverage、误推进计数和逐事件计算耗时。

## 本次结果与限制

- clean、漏一音、额外无关音，两种在线方法均正确定位本例全部可识别目标事件。
- 漏四音/前向跳段：当前方法覆盖2/8，OnlineDP覆盖5/8；OnlineDP在跳段后的第4个观测开始恢复连续两次正确定位，当前方法本片段未恢复。
- 连续同音处额外拨弦：两者均误推进1次，precision/coverage均11/12。仅靠音高序列不能可靠区分合法下一个同音与多拨一次。
- 回跳重弹：两者覆盖12/16，回跳的四个音未被正确对齐；尚不支持反复段结构或任意回跳恢复。
- unknown噪声、强置信度无关音：均无误推进；只是这些事件fixture，不等于真实噪声false-positive率。

无tempo状态或节奏代价：变速与停顿不影响音高序列结果，这不是节奏准确性证明。OnlineDP输出当前最优位置是假设，可能随着过去证据累积改变；不重写之前输出，也不适合直接作为不可撤销的教学判分。

这12个场景是开发回归，参数尚未在独立集验证。下一步应加入PCM识别输出、重复音上下文和结构/tempo模型；先保留本次误推进与回跳失败，不凭较高coverage替换在线主干。
