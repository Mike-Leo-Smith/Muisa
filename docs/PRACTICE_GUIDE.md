# 校准与第一课：开发可试流程

主页先呈现输入→底噪→六根空弦→轻/普通/较强拨弦→第一课。Debug 入口保留原音频实验台。所有数据只在本次页面会话内保留，不后台录音或上传；演示是数学 PCM 测试输入，不是产品音色示范。

## 校准含义

- 权限只由用户点击系统输入触发。底噪收集约 2 秒，使用与识别预处理相同的去 DC RMS 域，以中位数估计背景。数字静音、削波、明显瞬态和稳定有调音信号会提示重试。持续噪声或说话仍可能漏检，不能把这当通用降噪器。
- 默认 A4=440Hz、E2/A2/D3/G3/B3/E4 标准调弦。逐根要求置信度≥0.9、±25 cents、至少350ms稳定证据；相差八度明确提示倍频/音区问题，不折算成通过。只证明听到接近目标的音高，不证明拨的是哪根弦。
- 三种力度记录 RMS、峰值、粗略信噪差和音高 MAD。信噪差使用峰值窗口的信号加噪声 RMS 与安静段估计之比，并非独立分离噪声后的真实 SNR。结果只描述输入，不诊断手型、琴体或线材，也不能自动控制硬件增益。
- 每一步可以重试或手动继续，`manual-skip` 与 `measured` 分开；演示记录明确标注 synthetic-demo，不能充当真实设备通过。没有“必须六弦全绿”的门槛。
- 设备、流、采样率、实际浏览器处理设置、预处理开关变化或停止/断开输入会清空 profile 并停止练习。没有跨设备自动复用校准。

## 第一课

课程数据在 `src/lesson.js` 声明：1弦 E4（空弦）、F4（1品）、G4（3品）、E4。先解释半音与品，再跟弹→填空→无提示。跟弹与填空等待新的可信起音，未知说“没听清”，不同音高不推进；无提示模式连续8秒，结束后才显示离线顺序对齐反馈。

当前只判断有限音高顺序，没有示范伴奏、节拍器、完整节奏评分、端到端延迟校准或持久复习计划。开始前的迟到事件被排除。用户反应时间不作硬件延迟。无提示成功也不能代表识谱、听辨或全部演奏能力。

## 验证边界

Node 回归覆盖去 DC 校准、静音/混入音、错误音区与倍频、弱音/削波、手动跳过、profile 失效及三种练习模式。浏览器使用生成 PCM 经过实际 worker 校准、调弦与第一课，检查填空、盲弹延迟反馈、设置失效、音乐输入被拒作安静段以及已有权限/生命周期行为。

这些是程序和合成输入验证。尚无真实用户吉他、真实硬件链路或教学有效性验证；R1 真实录音诊断已显示明显漏听和误报，基础识别仍需改进。

## 重测语义修正

主测量按钮、Debug底噪按钮和Retry共用本次尝试失效规则：新尝试清空当前步骤旧成功结果，失败不保留measured，继续只记本次成功或manual-skip。开始背景测量时撤销旧noiseRms门限，并只在该测量期间强制去DC、使用未被旧门限屏蔽的pitch特征；结束恢复用户正常分析设置。持续弱琴音也可能污染背景，校准不等于已证明环境安静。
