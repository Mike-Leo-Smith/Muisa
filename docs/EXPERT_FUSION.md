# 专家融合：先量互补性，再考虑门控

状态：后续研究设计，没有训练门控、引入大 MoE 或改线上识别。当前优先完成 [N1 非平稳干扰评测](../experiments/nonstationary/README.md)。多算法可能互补，但已有证据不足以承诺实际识别率提升。

## R1 缓存只读互补性诊断

独立执行端分析原 R1 缓存，代码来源 `89feca126e3c14798b8f8c7b81b6ff903afa2a63`，配置 SHA256 `74156f09af63dbe885c417f07f52f02dc54ef657f991384aad727a0728a2e609`。没有新增推理、训练或修改标签。仅比较同一5119个eligible mono网格帧、50cents容差；这里的JS是原R1配置，不是W1短窗或在线输入链路。

JS正确3703，CREPE正确4805。假设知道每帧真值并总能选中正确专家，二者oracle union为4849/5119=94.73% pooled；CREPE本身为93.87%，理想上限只增加约0.86个百分点。整录音宏平均从85.3807%到86.0901%，增加0.7095个百分点。pooled与宏平均的分母/权重不同，不能混写。

再加入当前整段、非因果pYIN，oracle union为4944/5119=96.58% pooled；录音宏平均87.8619%，相对CREPE增加2.4812个百分点。这只是ground-truth逐帧挑选专家的理论上限，不是可部署收益。当前pYIN使用未来上下文，不能直接塞进实时门控。

这些union结果没有解决unvoiced false alarms，不包含音符/起音/offset或BasicPitch note F1，也没有计融合延迟、置信校准和错误切换。稳定mono仅占R1完整网格17.984%，不能拿这张表宣传全部吉他识别准确率。下一次融合评估必须同时包含负样本与拒识代价。

## 可执行设计边界（尚未实施）

1. **时间先对齐。** 每个候选带source sample clock、代表时刻、窗口起止、最早available time、平滑/lookahead等待及算法版本。比较同一声学时刻的候选；在线只能使用当前实际已available的信息，不能为了对齐读取未来。
2. **同任务候选才融合。** 单音F0候选、mono/poly判断、onset和release分开建接口及指标。不得把110Hz与220Hz直接平均成165Hz；保留八度竞争候选或unknown，结合谐波证据/历史做选择。候选在log-frequency/cents域聚类也不能消除真实八度歧义。
3. **置信度需要独立校准。** JS periodicity、CREPE activation和pYIN voiced probability不是可直接比较的正确率。若后续采用校准，必须另划校准数据和冻结测试集，检查reliability、coverage、FA以及噪声/音区分层。不能在R1或已看过结果的R2上反复选阈值再称未见测试。
4. **门控只用可观测特征。** 允许当前/历史电平、频谱、候选分歧、稳定性等；不允许真值mono/poly标签、正确音高或未来帧。保留unknown与迟滞，记录切换率、切换错误、前缀不变性和恢复时间。不能用目标谱先验强行把演奏判对。
5. **区分ensemble与条件计算。** 先全跑所有专家再门控是ensemble，不能声称省计算。真正cheap gate/fallback需要在预算内决定是否启动昂贵专家，并把冷启动、加载、首次/稳定输出延迟与峰值资源计入比较；不可只报专家内部compute。
6. **先小对照，后考虑学习门控。** N1完成后才考虑预注册一个简单共识/拒识策略，与单专家在同输入、同available时刻比较；保留噪声only和八度冲突负例。没有证据前不训练大模型、不自动换线上默认。

## 研究依据与适用限制

[Koguchi & Koriyama, ICASSP 2026](https://arxiv.org/abs/2602.01727)研究投票式F0融合，强调时间/频率对齐与低错误相关性的专家选择。其结果不能保证每个条件都超过最佳单模型，更不是对本项目吉他场景的泛化承诺；论文中的离线对齐也不能直接当作因果在线实现。

[Mauch & Dixon, pYIN, ICASSP 2014](https://webspace.eecs.qmul.ac.uk/s.e.dixon/pub/2014/MauchDixon-PYIN-ICASSP2014.pdf)提供概率候选和HMM/Viterbi路径思路。现有项目整段实现的非因果性必须保留在对照标签中；未来若做在线变体，应另测固定延迟和质量。

[Guo et al., ICML 2017](https://proceedings.mlr.press/v70/guo17a.html)说明分类模型的置信度可能失准，并研究温度缩放等校准方法。它不是对本项目F0分数已经校准的证明，也不保证单一温度能修复吉他音域、语音串入或采样分布变化。
