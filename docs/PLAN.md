# 产品与课程草案

## 目标与边界

面向个人练琴的轻量工具，按实际练习反馈迭代，不以商业差异化或首创为目标。每课同时解释一个音乐概念并练一个动作。以能脱离提示复现、隔天保留为目标，不将排行榜或单一分数当作学会。

分别记录音高准确、节奏稳定、短片段记忆、识谱、听辨及隔天保留。无提示复现仅证明这一片段的记忆与执行；不能据此宣称能识谱、听音或即兴。

MVP：标准调弦下第一弦（最细弦）空弦 E4、一品 F4、三品 G4，自制四小节、4/4、60 BPM、每两拍一个音。数字谱上的 0/1/3 是品位，不能当作音高识别的弦位证据。进入课程前需确认调弦；App 不能通过音频判断手型。第一课先解释“弦、品、音高、拍、两拍一个音”，示范后允许自由探索。

完整课程循环：短讲解 → 示范 → 自由练习 → 跟拍 → 填空 → 无提示复测 → 隔天复习。按更新后的优先级，本次不实现教学流程，先搭音频实验台。无提示允许开始前数拍，演奏中不提示目标音、不显示走到哪个音、不打断；是否保留节拍器另做独立难度设置。

练习模式以后支持等音、暂停、降速和局部重练；挑战模式时间连续，错音也继续。当前没有教学时钟或练习模式。阶段之间由用户选择继续或重试，完成演示不自动授予掌握状态。

## 分阶段验收

| 阶段 | 范围 | 验收 |
| --- | --- | --- |
| P0 本次 | 计划、接口、通用输入/文件实验台、单音/起音、候选和弦与短谱对齐 | PCM 级自动测试、文件解码、假麦克风浏览器测试；明确未知与失败样例 |
| P1 信号验证 | 真实录音集、改进检测与抗噪、链路校准 | 固定人工标注录音集覆盖安静、噪声、静音、削波和断流；报告音高误差、起音误差、覆盖率、未知率，而非只报正确率 |
| P2 真琴闭环 | 可插拔 PCM 输入、设备检查、耳机/扬声器回授检查 | 在实际吉他与选定输入链路测延迟；换设备后校准失效；拒绝权限/拔线能恢复，不判为演奏错误 |
| P3 学习闭环 | 短讲解、示范、等音练习、复习记录 | 首次、撤提示后、隔天均单独留记录；技能指标独立，识谱/听辨有独立题型 |

初始评分阈值只是设计参数（起音 ±250 ms、音高 ±50 cents、置信度 0.8），必须用真实样本调参。持续音时长、额外音符、连音、杂音尚不评分。用户可以绕过前阶段进行产品试用，正式课程晋级规则留待实测。

后续优先按实际需要组合跟谱、慢速、局部 loop、反馈、填空与无提示。课程音符、速度、难度和检测阈值应可配置，先小规模手工修改声明式数据，不提前建大型内容平台。保留原始/处理后对照与错误分析，方便定位某次实际练琴的误判；未来录音保存仅在用户主动操作后写本地，不后台收集。

不在 MVP：任意和弦多音精确拆解、视频姿态、版权曲库、登录支付社交。采用自制片段。原始音频默认留本机，未来上传需要显式选择；云端当前只承载开发工程，实时评分设计在客户端运行。
