# 竞品背景（2026-11-02）

官方文档调研摘要，未进行实机横评；不扩大本轮音频实验范围。

- Yousician / Simply Guitar / Rocksmith+ / Fender Play 已有真实音频反馈，六线谱、慢练和实时反馈不能视为独占创新。[Yousician 和弦说明](https://support.yousician.com/hc/en-us/articles/202893201-Chords-are-not-recognized)提到未听见的弦标红；这不意味着我们的混合 PCM 可以可靠确定实际弦位。
- [Fender Feedback Mode](https://play-instructor.fender.com/hc/en-us/articles/12795419880461-Feedback-Mode)提供音高/节奏演后反馈。[Simply 的 PLAY](https://piano-help.hellosimply.com/en/articles/14588852-what-is-play-in-simply-guitar)明确不判错，不能将该模式概括成整个产品不评估。
- [Soundslice](https://www.soundslice.com/teachers/)明确目前不自动评估演奏，但有手动隐藏谱面及图片/PDF OMR。[Guitar Pro Line In](https://support.guitar-pro.com/hc/en-us/articles/360000779397-GP8-Discover-the-Line-In-feature)不是自动转谱。[Songsterr](https://www.songsterr.com/help)的 AI 音频扒谱也不等于实时演奏判定；本轮没有证实后者。
- 历史 Rocksmith 2014 已有 Master Mode，不能声称提示渐隐或离屏演奏是首创。

教人读谱、谱面显示、音频转谱、图片 OMR、跟谱评估是不同能力。我们的提示撤除→隔天保持→迁移学习闭环是待验证方向，不是已经证明竞品缺失的功能。这些调研只供个人练琴功能借鉴，不承担商业定位或首创论证。先验证检测与对齐，再按用户实际学习情况组合慢练、loop、反馈与撤提示。
